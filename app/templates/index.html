CyberScan

ClamAV Scan WiFi/BT Base de données

Analyser un fichier

Le fichier est vérifié par ClamAV et par une analyse heuristique (hash connus, extensions, exécutables déguisés, chaînes suspectes).

Vulnérabilités (CVE)

Recherche dans la base officielle NVD si Internet est disponible, sinon dans la base locale. Tapez * pour tout afficher. Chaque CVE est enregistrée avec une solution proposée.

Scan WiFi

La carte WiFi de l'ordinateur (ou un ESP32 en option) liste les réseaux à portée. Les réseaux ouverts ou en WEP sont signalés comme risqués.

Scan Bluetooth

Liste les appareils Bluetooth connus de l'ordinateur (ou détectés par un ESP32 en option).

Historique

Tous les scans et CVE enregistrés dans la base PostgreSQL.
